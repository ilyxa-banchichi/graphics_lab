# Graphics Lab

Интерактивное веб-приложение о растеризационном графическом конвейере: путь одного треугольника от вершинных данных до пикселя в кадре. Слайды чередуются с живыми демонстрациями на WebGL 2.

Разделы: подготовка данных, обработка вершин, обработка примитивов, растеризация, обработка фрагментов, тест глубины и смешивание.

## Стек

React 19, TypeScript, Vite 7, three.js. Шейдеры написаны на HLSL и скомпилированы в GLSL ES 3.00.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev       # http://127.0.0.1:5173
npm run build     # сборка в dist/
npm run preview   # просмотр сборки
```

Навигация: кнопки «Назад» / «Далее», стрелки, Page Up / Page Down.

## Шейдеры

Исходники лежат в `shaders/`. `Pipeline.hlsl` используется в демонстрациях конвейера, `Scene.hlsl` в трёхмерных сценах, `LectureEffects.hlsl` содержит общие функции.

Цепочка компиляции: HLSL → DXC (SPIR-V) → SPIRV-Cross (GLSL ES 3.00). Результат сохранён в `src/generated/shaders.json`, поэтому для обычной сборки компиляторы не нужны. `npm run build` проверяет, что сгенерированные шейдеры соответствуют исходникам.

После изменения HLSL:

```sh
npm run shaders
```

Нужны `dxc` с поддержкой SPIR-V и `spirv-cross`. Пути можно задать через `LECTURE_DXC` и `LECTURE_SPIRV_CROSS`.

## Проверки

```sh
npm run qa
```

Проверяет числовую модель конвейера, пиксели GPU-рендера, навигацию по всем экранам и вёрстку на ширине 390, 850 и 1440 px. Нужны запущенный dev-сервер, Playwright и Chromium. Переменные: `LECTURE_PLAYWRIGHT` (путь к модулю Playwright), `LECTURE_CHROME` (браузер), `LECTURE_URL` (адрес сервера).

## Структура

| Путь | Назначение |
|---|---|
| `src/lecture.ts`, `src/catalog.ts` | Порядок экранов и тексты слайдов |
| `src/pipelineModel.ts` | Числовая модель: преобразования, отсечение, растеризация, интерполяция |
| `src/PipelineSlides.tsx` | Иллюстрации слайдов |
| `src/PipelineDemos.tsx`, `src/*Demos.tsx` | Интерактивные демонстрации |
| `src/PipelineCanvas.tsx`, `src/SceneView.tsx` | WebGL-рендер на three.js |
| `scripts/` | Компиляция шейдеров и браузерные проверки |
