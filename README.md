# Graphics Lab

Самостоятельные слайды и интерактивные материалы по компьютерной графике. Два набора в одном приложении:

- **Геометрия и пиксели** — 40 экранов: данные, преобразования, отсечение, растеризация, материалы, глубина и смешивание.
- **Сцена и кадр** — 30 экранов: команды, проходы, targets, тени, порядок поверхностей, Forward / Deferred, постобработка, граф зависимостей и SRP.

Новый набор содержит 17 слайдов и 13 демонстраций. По умолчанию открывается «Сцена и кадр». Группы выбираются сверху, все экраны группы доступны справа. Стрелки и Page Up / Page Down меняют экран. Демо и слайды идут единым потоком.

## Локальный запуск

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Нужен Node.js 20.19+ или 22.12+. Dev-сервер слушает только `127.0.0.1`. Публикация для работы приложения не требуется.

## Реализация кадра

React, TypeScript, Vite, three.js и WebGL 2. Шейдерные программы написаны на HLSL; DXC компилирует их в SPIR-V, SPIRV-Cross — в GLSL ES 3.00. Сгенерированные программы сохранены в репозитории, поэтому обычная сборка не требует компиляторов.

`FrameCanvas` выполняет реальные геометрические и полноэкранные проходы. Используются карта глубины света, цвет и глубина камеры, MRT G-buffer из двух цветовых attachments, перенос глубины для прозрачности, выделение яркого, разделимое размытие, tone mapping и композиция UI. GPU Instancing объединяет совместимые копии малых кубов в одну команду на проход.

В демо можно выбрать промежуточный ресурс, остановить кадр после прохода, отключить ветвь эффектов, изменить порядок прозрачных слоёв, разрешение и свойства света. Счётчики отражают реальные draw calls и число треугольников с учётом повторной отрисовки; вспомогательный вывод target исключён. Это не измерение GPU-времени.

G-buffer и схема освещения компактные и не копируют внутренние форматы URP. Список зависимостей строится явно и не является оптимизатором Unity Render Graph. UI показан плашкой. Полный диапазон HDR требует `EXT_color_buffer_float`; при отсутствии расширения приложение сообщает о RGBA8.

## Шейдеры

```sh
npm run shaders
```

Нужны `dxc` и `spirv-cross`. Для новых программ можно задать `GRAPHICS_DXC` и `GRAPHICS_SPIRV_CROSS`. Существующие программы геометрии также поддерживают прежние `LECTURE_DXC` и `LECTURE_SPIRV_CROSS`.

```sh
npm run typecheck
npm run qa:frame
npm run qa
```

`qa:frame` проверяет зависимости ресурсов во всех 32 комбинациях пути и основных переключателей, размеры ресурсов и структуру 30 экранов. `qa` дополнительно запускает прежние числовые и браузерные проверки геометрии. Для браузерных проверок нужны запущенный сервер, Playwright и Chromium; поддерживаются `LECTURE_URL`, `LECTURE_PLAYWRIGHT` и `LECTURE_CHROME`.

## Файлы

| Файл | Содержимое |
|---|---|
| `src/frameContent.ts` | 30 экранов и девять групп нового набора |
| `src/FrameSlides.tsx` | Схемы, таблицы, термины |
| `src/FrameDemos.tsx` | Управление и инспекция проходов |
| `src/FrameCanvas.tsx` | Исполнение WebGL-проходов |
| `src/frameModel.ts` | Описание ресурсов и зависимостей |
| `shaders/Multipass.hlsl` | Геометрия, тени, Forward и MRT |
| `shaders/ScreenPass.hlsl` | Deferred Lighting, bloom, tone mapping, UI |
| `scripts/compile-multipass.mjs` | Воспроизводимая компиляция новых HLSL-программ |

Маршруты новых материалов начинаются с `#frame/`, материалов геометрии — с `#geometry/`. Прежние `#lecture/`-ссылки принимаются как совместимые закладки, но интерфейс их не создаёт.
